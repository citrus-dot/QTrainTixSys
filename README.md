# 列车客运售票管理系统 - V9（车票展示与导出）

## 版本说明

本版本在 V8 基础上，售票成功后弹出"车票"卡片对话框，直观展示本次购票的完整信息，并支持将车票导出为文本文件。
对应题目要求：提供购票凭证，完善售票闭环体验。

## 功能

- **车票卡片**：售票成功后自动弹出，模拟纸质车票样式（金色边框 + 米色底）
  - 上半区：班次号、发车日期、发车时间、行程（发车城市 → 终点城市）
  - 下半区：乘客姓名、身份证号、座位（X号车厢 Y号座）、等级（一等座/二等座）、票价
- **车票导出**：点击"保存车票"按钮，将车票信息写入 `.txt` 文本文件（默认文件名 `班次号_姓名_车厢_座位.txt`）
- **V8 保留**：座位可视化网格（绿=空座、红=已售）、点击选座、退票模式、车厢切换
- **V7 保留**：日期/票价/等级字段、输入校验、文件格式向后兼容

## 文件结构

```
（V8 全部文件）
ticketview.ui      车票卡片布局（样式表 + 表单字段）
ticketview.h/cpp   车票数据填充、保存为 .txt
mainwindow.cpp     售票成功后弹出车票对话框
CMakeLists.txt     新增 ticketview 源文件
```

## 编译运行

用 Qt Creator 打开本文件夹的 `CMakeLists.txt`，选择 Qt 6.5+ 套件，构建并运行。

## 测试（联调清单）

1. **打开数据**：文件 → 打开 → `testdata.dat`
2. **售票出票**：选中班次 → 售票 → 点选空座并确认，售票成功后自动弹出车票卡片
3. **车票信息**：核对车票上的班次号/日期/时间/行程/乘客/身份证/座位/等级/票价与输入一致
4. **票价等级**：切换不同车厢购票，车票显示对应等级（一等座/二等座）与票价
5. **保存车票**：点击"保存车票"，选择路径后生成 `.txt`，内容与车票一致
6. **关闭车票**：点击"OK"关闭车票后，主窗口余票与座位表已同步刷新
