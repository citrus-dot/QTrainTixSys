# 列车客运售票管理系统 - V12（组件化重构）

## 版本说明

V12 完成 MainWindow 结构瘦身，将左侧班次列表和右侧座位登记表拆分为两个独立组件：
- `TrainListView`：封装搜索框 + 班次表格 + 实时过滤逻辑
- `SeatTableView`：封装座位登记表 + 已售座位填充逻辑
- MainWindow 最终只保留：文件操作、菜单/工具栏接线、对话框调度

拆分后代码职责清晰，每个组件只做一件事，后续功能扩展和维护更方便。单元测试全部通过，功能不受影响。

## 代码结构

```
数据层：
  seat.h/cpp                座位类：存储旅客信息（姓名/身份证/车厢/座位号）
  train.h/cpp               班次类：班次信息 + 所有座位 + 售票/退票操作 + 输入校验
  trainsystem.h/cpp         系统类：管理所有班次 + 文件读写

UI 组件：
  trainlistview.h/cpp       班次列表组件：搜索框 + 表格 + 实时过滤
  seattableview.h/cpp       座位登记表组件：显示已售座位
  mainwindow.h/cpp          主窗口：文件操作 + 菜单接线 + 对话框调度
  mainwindow.ui             主窗口布局

对话框：
  addtraindialog.h/cpp/ui   新增/修改班次对话框
  ticketdialog.h/cpp/ui     售票/退票对话框（含座位网格）
  ticketview.h/cpp/ui       车票展示对话框（可保存为 txt）
  querydialog.h/cpp/ui      查询对话框

测试：
  tests/tst_train.cpp       Seat/Train 单元测试
  tests/tst_system.cpp      TrainSystem 单元测试 + 文件读写测试

构建：
  CMakeLists.txt            CMake 构建配置
  .gitignore               Git 忽略规则（build/ 等）

文档：
  README.md                本文件（版本说明 + 功能 + 文件说明 + 编译运行）
  PROGRESS.md              迭代计划与进度
  testdata.dat              示例测试数据
```

## 测试

1. **运行单元测试**：`ctest --test-dir build --output-on-failure`
2. **打开数据**：文件 → 打开 → `testdata.dat`
3. **售票**：选中班次 → 操作 → 售票 → 点击空座 → 填姓名身份证 → 确定
4. **退票**：选中班次 → 操作 → 退票 → 点击已售座位 → 确定
5. **查询**：选中班次 → 操作 → 查询，或主窗口搜索框输入关键字
6. **导入数据**：文件 → 保存 → 所有班次和旅客信息写入 .dat 文件
7. **车票导出**：售票成功弹出车票 → 点"保存车票" → 保存为 .txt
