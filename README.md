# 列车客运售票管理系统 - V5（查询与中间停靠）

## 版本说明

本版本在 V4 基础上，加入**查询对话框**和**中间停靠站**信息。
对应题目要求：基本查询功能；可选功能提升（查询指定班次的余票数和座位号、增加起点和终点的中间停靠信息）。

## 功能

- 查询对话框（操作 → 查询...，快捷键 Ctrl+Q）：
  - 下拉框选择班次
  - 显示发车时间、发车城市、终点城市、余票数
  - 列表显示该班次所有**可选座位号**
  - 列表显示该班次的**中间停靠站**
- 新增班次对话框增加“中间停靠”输入框（逗号分隔，可留空）
- 中间停靠站随数据文件一起保存/读取

## 文件结构

```
（V4 全部文件）
querydialog.h / querydialog.cpp / querydialog.ui   查询对话框
addtraindialog.ui / addtraindialog.cpp             新增班次对话框增加停靠站输入
```

## 编译运行

用 Qt Creator 打开本文件夹的 `CMakeLists.txt`，选择 Qt 6.5+ 套件，构建并运行。

## 测试

- 新增班次时填写中间停靠站（如“徐州,济南”），保存后重新打开，确认停靠站仍在
- 打开查询对话框，切换不同班次，确认余票数和可选座位号随售票情况变化
- 售票若干座位后再次查询，确认可选座位号列表减少
- 对无停靠站的班次查询，确认停靠站列表为空
