# 列车客运售票管理系统 - V6（测试数据与联调）

## 版本说明

本版本为**最终版**，在 V5 基础上提供测试数据文件，并完成全面联调。
对应题目要求：设计各种可能的数据（测试对象）对程序进行测试，确保可见范围内的测试对象都能得到正确结果。

## 功能

- 提供 `testdata.dat` 测试数据文件，包含 3 个班次：
  - `G101` 南京→北京，2 车厢 × 5 座，停靠：徐州、济南，已售 2 张
  - `D301` 上海→广州，2 车厢 × 5 座，停靠：杭州、南昌、长沙，已售 3 张
  - `K512` 南京→成都，1 车厢 × 5 座，停靠：合肥、武汉、重庆，已售 1 张
- 覆盖场景：多班次、多停靠站、不同车厢数、已售/空座混合、余票计算

## 文件结构

```
（V5 全部文件）
testdata.dat   测试数据文件（文件 → 打开 载入）
```

## 编译运行

用 Qt Creator 打开本文件夹的 `CMakeLists.txt`，选择 Qt 6.5+ 套件，构建并运行。

## 测试（联调清单）

1. **打开数据**：文件 → 打开 → 选择 `testdata.dat`，确认 3 个班次显示正确
2. **余票校验**：G101 余票应为 8（10-2），D301 为 7（10-3），K512 为 4（5-1）
3. **座位登记**：点击各班次，确认已售旅客信息正确显示
4. **售票**：对空座售票，确认余票减少、座位登记表新增旅客
5. **退票**：对已售座位退票，确认余票增加、旅客信息移除
6. **查询**：查询对话框确认余票数、可选座位号、停靠站正确
7. **保存往返**：保存为另一文件后重新打开，确认数据一致
8. **异常输入**：重复售票、空座退票、空姓名售票均被正确拦截
