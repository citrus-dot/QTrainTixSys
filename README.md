# 列车客运售票管理系统 - V3（新增/删除班次）

## 版本说明

本版本在 V2 基础上，加入**新增班次对话框**和**删除班次**功能。
对应题目要求：创建和管理描述每个班次基本信息的对象。

## 功能

- 新增班次对话框（操作 → 新增班次...）：
  - 输入班次号、发车时间、发车城市、终点城市
  - 选择车厢数、每厢座位数
  - 校验班次号不能为空
  - 班次号重复时提示“班次号已存在”
- 删除班次（操作 → 删除班次）：删除当前选中的班次，删除前弹出确认框
- 新增/删除后自动刷新班次表格和座位登记表

## 文件结构

```
（V2 全部文件）
addtraindialog.h / addtraindialog.cpp / addtraindialog.ui   新增班次对话框
```

## 编译运行

用 Qt Creator 打开本文件夹的 `CMakeLists.txt`，选择 Qt 6.5+ 套件，构建并运行。

## 测试

- 新增一个班次，填写完整信息，确认出现在班次表格中
- 新增两个相同班次号，确认第二个被拒绝并提示
- 选中一个班次后删除，确认表格刷新且座位登记表清空
- 保存文件后重新打开，确认班次信息完整
