# 列车客运售票管理系统 - V11（单元测试）

## 版本说明

本版本为数据层（`Seat`/`Train`/`TrainSystem`）引入 Qt Test 单元测试，并通过 CTest 集成，为后续重构（V12）与功能扩展（V14）建立自动化回归安全网。

## 功能

- **单元测试（Qt Test）**：
  - `tests/tst_train.cpp`：`Seat` 构造/旅客设置清除；`Train` 售票（成功/重复/越界）、退票（成功/空座/越界）、余票计算、按车厢可选座位、等级票价、静态校验（时间/日期/身份证）
  - `tests/tst_system.cpp`：`TrainSystem` 增删查、班次号查重、文件读写往返（逐字段一致）、旧格式向后兼容加载
- **CTest 集成**：`ctest` 一键运行全部测试；测试不依赖 GUI（不链接 Widgets）
- **V10 保留**：班次实时筛选与搜索
- **V9 保留**：售票后车票展示与导出
- **V8 保留**：座位可视化网格（绿=空座、红=已售）、点击选座、退票模式
- **V7 保留**：日期/票价/等级字段、输入校验、文件格式向后兼容

## 代码审查与精简（V10.1）

- 座位登记表只显示已售座位（不再铺满空座）
- 查询对话框可选座位按车厢显示（"X号车厢 Y号座"）
- 新建/打开文件时自动清空搜索框
- 新增班次增加发车/终点城市非空校验
- 删除未使用的 `Train::setPrices()`，`availableSeats()` 改为按车厢查询

## 文件结构

```
tests/tst_train.cpp   核心类（Seat/Train）单元测试
tests/tst_system.cpp  系统类（TrainSystem）单元测试 + 文件读写/兼容测试
CMakeLists.txt        新增 tst_train / tst_system 测试目标 + CTest 注册
```

## 编译运行

用 Qt Creator 打开本文件夹的 `CMakeLists.txt`，选择 Qt 6.5+ 套件，构建并运行。

## 测试（联调清单）

1. **运行单元测试**：`ctest --test-dir build --output-on-failure`（或 Qt Creator 中运行 `tst_train`/`tst_system`），全部通过
2. **打开数据**：文件 → 打开 → `testdata.dat`
3. **按班次号筛选**：搜索框输入班次号（如 `G`），表格仅显示匹配班次
4. **按城市筛选**：输入发车城市或终点城市名称，表格实时过滤；不区分大小写（输入英文/中文均可）
5. **无匹配**：输入不存在的关键字，表格清空、座位登记表同步清空
6. **清空恢复**：点击搜索框右侧清除按钮，恢复显示全部班次
7. **筛选后操作**：在过滤结果中选中某班次 → 售票/退票/删除，目标班次正确
8. **数据一致**：筛选状态下售票/退票后，过滤结果中的余票同步刷新
