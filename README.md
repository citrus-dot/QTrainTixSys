# 列车客运售票管理系统 - V8（座位可视化网格）

## 版本说明

本版本在 V7 基础上将售票/退票对话框改造为可视化座位网格，取代手动输入车厢/座位号。
对应题目要求：直观展示座位占用状态，提升售票/退票操作体验。

## 功能

- **座位可视化网格**：售票/退票对话框中部显示当前车厢座位网格
  - 每排 5 座，绿色 = 空座，红色 = 已售
  - 已售座位悬停显示乘车人姓名
  - 车厢下拉切换，显示各车厢等级（一等座/二等座）
- **点击选座**：
  - 售票模式：点击绿色空座 → 高亮选中，自动填充车厢/座位
  - 退票模式：点击红色已售座位 → 高亮选中
  - 再次点击已选座位可取消选择
- **实时提示**：底部显示"已选: X号车厢 Y号座 (等级)"或选座引导
- **校验保留**：售票校验姓名/身份证号（18 位），退票校验座位已售

## 文件结构

```
（V7 全部文件）
ticketdialog.ui     布局改造：座位网格 + 车厢下拉 + 图例
ticketdialog.h/cpp  网格着色/点击选座/模式切换逻辑
（train.h/cpp 复用 V7 的 isSeatOccupied，无改动）
```

## 编译运行

用 Qt Creator 打开本文件夹的 `CMakeLists.txt`，选择 Qt 6.5+ 套件，构建并运行。

## 测试（联调清单）

1. **打开数据**：文件 → 打开 → `testdata.dat`
2. **售票网格**：选中班次 → 售票，确认车厢 1 的 1、2 号座显示红色（已售），其余为绿色
3. **点击选座**：点击绿色空座，底部显示"已选: 1号车厢 3号座"且高亮；点击已选座位可取消
4. **车厢切换**：切换车厢下拉，网格随之刷新，且显示"1号车厢 (一等座)/2号车厢 (二等座)"
5. **已售悬停**：鼠标悬停红色座位，显示乘车人姓名
6. **售座拦截**：售票模式下点击红色已售座位无反应
7. **退票模式**：切换退票，点击红色座位完成选座；点击绿色空座无反应
8. **校验**：售票未填姓名/身份证被拦截；身份证非 18 位被拦截；未选座确认被拦截
9. **数据一致**：售票/退票后主窗口余票与座位表同步刷新
