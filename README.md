# 列车客运售票管理系统 - V7（数据模型扩展与校验）

## 版本说明

本版本在 V6 基础上扩展数据模型并加强输入校验，为后续"座位可视化"与"车票展示"打数据基础。
对应题目要求：对输入数据（时间、日期、票价、身份证号）进行合法性校验，确保数据正确性。

## 功能

- **数据模型扩展**：班次新增发车日期、一等/二等票价、每车厢等级（1=一等座 2=二等座）
- **输入校验**：
  - 发车时间格式 `HH:MM`
  - 发车日期格式 `YYYY-MM-DD`（日历选择）
  - 票价必须大于 0
  - 身份证号 18 位（17 位数字 + 数字或 X/x）
- **新增班次对话框**：新增发车日期（QDateEdit 日历）、一等/二等票价、一等车厢数输入
- **查询对话框**：显示日期、一等/二等票价、一等座所在车厢
- **主窗口**：班次表新增"发车日期"列
- **文件格式扩展**：班次行追加 `日期 一等票价 二等票价 各车厢等级`，兼容读取旧格式文件（缺字段给默认值）
- `testdata.dat` 更新为新格式，含日期、票价、车厢等级数据

## 文件结构

```
（V6 全部文件）
train.h/cpp            数据模型扩展：日期/票价/车厢等级 + 校验静态方法
trainsystem.cpp        文件读写：新格式保存 + 旧格式向后兼容加载
addtraindialog.ui/cpp  新增日期/票价/一等车厢数输入与校验
querydialog.ui/cpp     显示日期/票价/等级
mainwindow.cpp         班次表新增发车日期列
testdata.dat           新格式测试数据
```

## 编译运行

用 Qt Creator 打开本文件夹的 `CMakeLists.txt`，选择 Qt 6.5+ 套件，构建并运行。

## 测试（联调清单）

1. **打开数据**：文件 → 打开 → 选择 `testdata.dat`，确认 3 个班次及日期列显示正确
2. **余票校验**：G101 余票应为 8（10-2），D301 为 7（10-3），K512 为 4（5-1）
3. **查询显示**：查询对话框确认日期、一等/二等票价、一等座车厢号正确
4. **新增班次**：填写日期/票价/一等车厢数，确认新增成功且主表显示日期
5. **非法时间**：发车时间填 `25:00` 或 `8:00`，应被拦截
6. **非法票价**：票价填 0，应被拦截
7. **非法身份证**：售票时身份证号非 18 位，应被拦截
8. **旧格式兼容**：用 V6 的旧格式数据文件打开，应能正常读取（日期/票价显示为空或默认）
9. **保存往返**：保存为另一文件后重新打开，确认日期/票价/等级数据一致
