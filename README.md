# 列车客运售票管理系统 - V4（售票/退票）

## 版本说明

本版本在 V3 基础上，加入**售票/退票对话框**，实现座位旅客登记信息的创建与管理。
对应题目要求：创建和管理座位信息对象（售票时实现）、办理售票（座位号不能重复）、办理退票。

## 功能

- 售票/退票对话框（操作 → 售票... / 退票...）：
  - 单选按钮切换“售票 / 退票”模式
  - 售票时填写姓名、身份证号，选择车厢号、座位号
  - 退票时只需选择车厢号、座位号（姓名/身份证号输入框自动禁用）
- 校验逻辑：
  - 售票：姓名和身份证号不能为空；座位已被占用时提示
  - 退票：座位没有旅客时提示“无法退票”
- 售票/退票成功后自动刷新座位登记表和班次表格（余票数更新）

## 文件结构

```
（V3 全部文件）
ticketdialog.h / ticketdialog.cpp / ticketdialog.ui   售票/退票对话框
```

## 编译运行

用 Qt Creator 打开本文件夹的 `CMakeLists.txt`，选择 Qt 6.5+ 套件，构建并运行。

## 测试

- 选中一个班次，售票：填写姓名、身份证号、车厢号、座位号，确认座位登记表出现该旅客
- 对同一座位再次售票，确认提示“该座位已被占用”
- 退票：选择已售票座位，确认旅客信息从座位登记表移除，余票数增加
- 对空座退票，确认提示“该座位没有旅客，无法退票”
- 保存后重新打开，确认售票/退票结果已持久化
