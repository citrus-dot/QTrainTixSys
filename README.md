# 列车客运售票管理系统 - V2（主窗口界面）

## 版本说明

本版本在 V1 核心类基础上，加入 **Qt Widgets 图形界面**：主窗口、菜单、工具栏、双表格。
对应题目要求：基本信息显示（所有班次 + 座位登记表）、数据文件读写、菜单与信号槽交互。

## 功能

- 主窗口：左侧“所有班次”表格，右侧“座位登记表”表格（左右可拖动分隔）
- 班次表格列：班次号、发车时间、发车城市、终点城市、车厢数、每厢座位数、余票
- 座位登记表列：车厢号、座位号、姓名、身份证号
- 菜单栏：文件（新建/打开/保存/退出）、帮助（关于）
- 工具栏：打开、保存
- 点击班次表格某一行，右侧显示该班次的座位登记表
- 数据文件打开/保存（`.dat` 格式）

## 文件结构

```
seat.h / seat.cpp         座位类
train.h / train.cpp       班次类
trainsystem.h / trainsystem.cpp   管理系统类
mainwindow.h / mainwindow.cpp / mainwindow.ui   主窗口
main.cpp                  程序入口
CMakeLists.txt            构建配置（Qt Core + Widgets）
```

## 编译运行

用 Qt Creator 打开本文件夹的 `CMakeLists.txt`，选择 Qt 6.5+ 套件，构建并运行。

## 测试

- 文件 → 打开，选择 V6 提供的 `testdata.dat`（或自行新建班次后保存），确认班次和座位显示正确
- 文件 → 保存，确认 `.dat` 文件生成
- 点击不同班次行，确认座位登记表随之切换
