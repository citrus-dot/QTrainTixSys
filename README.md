# 列车客运售票管理系统 - V10（筛选与搜索）

## 版本说明

本版本在 V9 基础上，在"所有班次"表格上方增加实时搜索框，输入关键字即可按班次号、发车城市或终点城市筛选班次，方便快速定位列车。

## 功能

- **实时筛选**：搜索框输入内容后，班次表格立即按关键字过滤
  - 匹配范围：班次号、发车城市、终点城市（`QString::contains`，不区分大小写）
  - 空关键字显示全部班次
- **一键清空**：搜索框内置清除按钮（`clearButtonEnabled`），点击即可恢复全部班次
- **操作不受影响**：筛选后选中行仍能正确对应真实班次（按班次号定位，售票/退票/删除目标准确）
- **V9 保留**：售票后车票展示与导出
- **V8 保留**：座位可视化网格（绿=空座、红=已售）、点击选座、退票模式
- **V7 保留**：日期/票价/等级字段、输入校验、文件格式向后兼容

## 文件结构

```
（V9 全部文件）
mainwindow.ui     班次表格上方新增搜索框 searchEdit
mainwindow.h/cpp  搜索信号连接、按关键字过滤刷新、currentTrain 改按班次号定位
```

## 编译运行

用 Qt Creator 打开本文件夹的 `CMakeLists.txt`，选择 Qt 6.5+ 套件，构建并运行。

## 测试（联调清单）

1. **打开数据**：文件 → 打开 → `testdata.dat`
2. **按班次号筛选**：搜索框输入班次号（如 `G`），表格仅显示匹配班次
3. **按城市筛选**：输入发车城市或终点城市名称，表格实时过滤；不区分大小写（输入英文/中文均可）
4. **无匹配**：输入不存在的关键字，表格清空、座位登记表同步清空
5. **清空恢复**：点击搜索框右侧清除按钮，恢复显示全部班次
6. **筛选后操作**：在过滤结果中选中某班次 → 售票/退票/删除，目标班次正确
7. **数据一致**：筛选状态下售票/退票后，过滤结果中的余票同步刷新
